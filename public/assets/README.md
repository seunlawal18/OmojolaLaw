# Assets

Place the following files in this directory:

| Filename                  | Description                                                        |
|---------------------------|--------------------------------------------------------------------|
| `courthouse-sequence.mp4` | ✅ Already added — cinematic scroll-driven hero video               |
| `courthouse-poster.jpg`   | Static poster/fallback shown while video loads (optional)          |
| `logo-color.png`          | Color logo (gold/red crest) — used in navbar + browser favicon     |
| `logo-white.png`          | White logo — used in footer and navbar over the dark cinematic hero|
| `attorney.jpg`            | Attorney Ade Omojola portrait photo                                |

All paths are centrally configured in `src/config/site.ts` under `media`.
Change any filename there and it updates everywhere automatically.
