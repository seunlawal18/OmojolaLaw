# Omojola Law

**New Jersey Law Firm — Protecting Your Rights**

Premium law firm website for Attorney Ade Omojola, built with React + TypeScript + Vite + Tailwind CSS v4.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- React Router v6
- Lucide React

## Features

- Cinematic scroll-driven courthouse video hero
- Practice area pages (Litigation, DUI/DWI, Domestic Violence & Family, Immigration)
- Attorney profile, client reviews carousel, FAQ accordion
- Service areas section
- Legal Insights YouTube video section with modal player
- Interactive Google Maps embed (Toms River office)
- Contact form with validation
- Fully responsive — mobile-first
- Accessible (semantic HTML, ARIA, keyboard nav, reduced-motion support)
- SEO meta tags + structured data

## Getting Started

```bash
npm install
npm run dev
```

## Assets

Place the following in `/public/assets/`:

## Deployment

Hosted on Vercel. The `vercel.json` rewrite rule handles SPA client-side routing.
